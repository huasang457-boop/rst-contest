## 必做题：个人在线简历

目录 `resume/`。原生 HTML + CSS + JavaScript，**零外部依赖**——无 CDN、无字体服务、无框架、无构建步骤，双击 `resume/index.html` 即可查看，断网也能完整显示。

- 响应式：375 / 768 / 1280 三档实测，无横向滚动
- 深浅主题切换，选择记忆到 `localStorage`
- 滚动进入视口渐显（`IntersectionObserver`）
- 首屏错落入场动画
- 首屏背景为纯 CSS 绘制的戈壁地平线，无图片素材
- 含打印样式表，可另存为 PDF

## 附加题：坦克大战

目录 `tank-game/`。Python + pygame。

```bash
cd tank-game
pip install -r requirements.txt
python main.py
```

Windows 用户可直接双击 `tank-game/运行游戏.bat`。

- **底图**：程序化绘制的「浩源 · 浪尖儿大学生社区」校园黄昏场景
- **身份标识**：战场中央砖墙拼出 `WZQ`，另有信息栏徽标、基地旗帜与底图水印
- **原创性**：全部美术与音效由代码生成，项目内无任何第三方图片或音频文件

详见 [`tank-game/README.md`](tank-game/README.md)。
