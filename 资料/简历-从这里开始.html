技术说明

项目说明
技术栈原生 HTML5 + CSS3 + JavaScript，ES5 语法，兼容性优先
外部依赖零。无 CDN、无字体服务、无框架、无构建步骤，断网也能完整显示
文件组织index.html 结构 / style.css 样式 / script.js 交互，三层分离
响应式375px、768px、1280px 三档实测，无横向滚动
无障碍语义化标签、aria 属性、键盘焦点样式、支持「减少动态效果」系统偏好
附加含打印样式表，浏览器可直接另存为 PDF

实现的交互

  • 深色 / 浅色主题切换：默认跟随系统，手动切换后记忆到 localStorage
  • 滚动进入视口渐显：IntersectionObserver 实现，仅触发一次；JS 失效时内容仍完整可读
  • 首屏错落入场动画：分级延迟，一次编排完成
  • 移动端汉堡菜单：含展开收起动画与 aria-expanded 状态
  • 纯 CSS 绘制的戈壁地平线：首屏背景无任何图片素材

视觉方向

西北 / 新疆地域配色：戈壁米白底、沙岩赭主色、胡杨金强调色，深色主题切换为夜空靛蓝，呼应就读院校所在地。
