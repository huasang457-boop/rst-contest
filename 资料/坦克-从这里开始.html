怎么运行

需要电脑上已安装 Python 3.8+。启动脚本会自动检测并安装 pygame 依赖， 但不会自动安装 Python 本身——若未安装，脚本会给出提示并退出。 不方便配置环境的话，上方的演示动画与下方的截图已能完整反映游戏内容。

方式 1（推荐）：双击 tank-game/运行游戏.bat，脚本会自动检测环境并安装依赖后启动。

方式 2：命令行

cd tank-game
pip install -r requirements.txt
python main.py

环境要求：Python 3.8+、pygame 2.x。开发测试环境为 Python 3.12 + pygame 2.6.1。

玩法

歼灭全部 12 辆敌方坦克，同时守住底部基地。3 条命，基地被摧毁也算失败。

  • 金色砖墙（拼成 WZQ 字样的那些）经过加固，需连续命中 3 次才会塌，中途显示裂纹
  • 水面坦克过不去，但炮弹可以飞过——能隔水对射
  • 树林坦克可从下方穿过，绘制在最上层，适合埋伏
  • 敌人分三种：普通兵 100 分、快速兵 200 分、装甲兵（3 血）300 分

赛题加分点对照

1. 底图与场景设计

game/background.py 程序化绘制的「浩源 · 浪尖儿大学生社区」校园黄昏场景，由远及近包含：黄昏渐变天空、夕阳光晕、两层远山、教学楼群剪影（带随机亮灯窗户）、校名灯箱横幅、校道与行道树、操场跑道与分道线、草坪 WZQ 水印，最后叠一层压暗以保证游戏元素可读性。原创，无第三方素材。

2. 身份标识（三重）

  • 地图布局：战场正中央由砖墙拼出 W Z Q，用金色砖块与普通砖墙区分。字母点阵定义在 game/level.py 的 LETTER_BITMAPS（6×8 点阵），由 _place_initials() 逐点写入地图网格
  • 界面标识：右侧信息栏顶部 WZQ 徽标、实时「缩写砖墙完好度」进度条、开始界面 WZQ 砖墙缩略图、基地旗帜 W 徽标
  • 底图水印：校园草坪上的 WZQ 大字水印

3. 原创性

全部美术与音效均由代码生成，项目内不含任何第三方图片或音频文件。砖块、钢板、水面、树林、坦克、爆炸全部用 pygame.draw 现画并缓存；音效用 array 合成 16 位 PCM 波形交给 pygame.mixer 播放。没有声卡的环境会自动降级为静音，不影响运行。
